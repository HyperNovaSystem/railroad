# Railroad — DOMECS exemplar

**▶ Live demo: https://hypernovasystem.github.io/railroad/**

Railroad tycoon game

## Features
* Build an enduring railroad business across generations
* Tech-tree: from basic rails to maglev, tunnels and beyond
* Passengers, cargo, etc. — pick what each train hauls; freight only loads
  where the station's good matches
* Track wears down and slows trains; pay to overhaul lines
* Political & social pressures
* Win by securing the dynasty's legacy (retire in glory) — or go bankrupt
* Interactive tutorial mode (toggle with 🎓 or `T`)
* Undo/redo any action (`Z` / `Y`), save/load in the browser

## Development

```sh
npm install   # expects the domecs workspace checked out as a sibling (../domecs)
npm test      # typecheck + vitest
npm run dev   # vite dev server
```
